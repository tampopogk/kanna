# Firebase Hosting site lookup compatibility

## Goal

Allow `kd cloud deploy` to take its existing idempotent account-Hosting-site creation path when the current Firebase CLI reports that the resolved account site is absent.

## Scope and constraints

- Recognize `Error: could not find site <site> for project <project>.` alongside the existing `requested entity was not found` diagnostic.
- Continue failing closed for authentication, network, and all other lookup failures.
- Do not deploy or create Firebase resources, access credentials, or alter Firebase targets.

## Done when

Focused kd tests cover the current missing-site diagnostic and non-absence lookup failures remain fatal.
