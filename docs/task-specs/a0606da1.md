# Firebase Functions npm lockfile synchronization

## Goal

Make Firebase Functions' npm lockfile agree with its declared Apple App Store server library dependency so Firebase's clean `npm ci` packaging install succeeds.

## Scope and constraints

- Synchronize `services/firebase-functions/package-lock.json` with the existing `@apple/app-store-server-library` 3.1.0 manifest entry and its transitive dependencies.
- Preserve declared dependency versions and Functions/billing behavior.
- Verify an isolated Firebase Functions `npm ci` followed by its build, without deploying or using secrets.

## Done when

The clean install and build succeed, and a focused test detects future manifest/lockfile drift.
