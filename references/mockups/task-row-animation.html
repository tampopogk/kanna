Task rows: arrive, leave, change place

When a task's row enters, leaves or changes place in one of the four lists (the Desk view's Desk rows, its Shelf rows, the strip under the active task, and the Merge queue tab's list), it moves for 0.2 s, ease-out cubic-bezier(0.2, 0, 0, 1): an arriving row fades in while the rows below slide down; a leaving row fades out while the rows below slide up; a row that changes place slides there. No bounce, no scale. Every row is already in its final place the moment the list updates: what you see moving is a picture over it, so a click lands where the row now is.

More than 3 rows arriving, leaving or changing place in one update, the first showing of a list, a search, and Reduce Motion all update the list at once. Each update below says what the app's debug output would say.
