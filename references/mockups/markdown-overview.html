Markdown overview: the code pane's overview on the markdown pane and its diff mode

The same OverviewView as code and diff panes, given a picture of the rendered page: the text column (from the change bars to its right edge) shrunk to the thumbnail's 84 pt width, so headings, code panels, tables, diagrams and images keep their shape. The picture is drawn when the doc reloads, re-lays out (its width changes) or changes look (appearance, a comment's tint), never on scroll: the readout counts the pictures drawn. Marks as in code and diff: the diff's added, removed and changed blocks in the colours of its change bars, open comments, find hits. Hidden when the doc fits or when the text column beside it would keep fewer than 80 columns of the body font at the pane's zoom; the comment list stays and the overview gives way first.
