Quiz: the agent asks about what the agents built

A round of five multiple-choice questions about what landed on main in the last day, asked one at a time by an agent in its chat, about two minutes. The planning agent offers a round when something has merged in the last day; yes runs kanna quiz open, which opens a Quiz window laid out like a Desk: the quiz agent docked on the left, in the repo on main (not a task, no worktree: the quiz changes nothing), and what it opens as tabs on the right. Close the window to stop; nothing is kept. Each answer gets a short explanation, and the agent opens the code at the line with kanna comment. A pick-the-drawing question writes its three drawings, A, B and C, in one markdown file and opens it beside the agent. It's the kanna-quiz skill: the planning agent opens the window with kanna quiz open, and the agent there writes each question itself from what's on main. Click an answer in the chat, or press its number.
