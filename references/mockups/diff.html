Diff viewer: what the task changed, as a tab beside its agent

kanna open diff [ARGS] opens a diff pane showing what git diff [ARGS] shows, in the task's worktree, file by file, highlighted. It takes git's arguments as git does: no arguments is what isn't staged; --merge-base main is everything the task changed since it left main, committed or not; --staged, main...HEAD, -- PATH as in git. It follows the worktree: when the agent edits or commits, the pane re-diffs and marks what moved. Split shows old and new side by side. Read-only: you review, select, copy, and open a file in a code pane.
