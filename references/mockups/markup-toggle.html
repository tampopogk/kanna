Turning markup on in a doc that's already open

Every markdown pane, and every web pane showing a local page, has the bar at the top. Beside the file path (and vs main when its changes are marked) is Comments: unlit when off, lit when on. Turning it on adds the agent chip, Threads and the marks, in place: same scroll, zoom and selection. Off takes them away and leaves the threads in the file.

Where the comments go depends on where the doc is: a Desk task's docked agent, the planner in the Desk view, or, in a free window, an agent you pick. kanna markup FILE from an agent reuses a pane in its own workspace that already shows FILE.
