Blocked tasks: a Shelf task waits until its blockers are Done

The Desk view: the planning agent on the left, the Desk's tasks and the Shelf on the right. A blocked row shows what it waits for and can't be moved to the Desk; clicking it says why. Type a kanna command in the planning pane as the agent would: kanna task new "NAME" "MESSAGE" --after t12, kanna task edit t14 --after none, kanna task done t12, kanna task start t13, kanna task list.
