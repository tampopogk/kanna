Doc markup: comment on a markdown file, and the agent beside it answers

A thread waiting on the agent shows three dots where the reply will land while the agent is working, then the reply replaces them; if the agent stops without answering, a quiet line says so instead. A thread's dot on a page carries small dots too. Try the agent states above the window.

The markdown pane is a preview. Select text and press ⌘↵, or ⌘-click a word, to comment. Posting types the comment into the agent that opened the doc, then Enter, the same for every agent.
