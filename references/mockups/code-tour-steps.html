Code tour steps: the agent queues a tour, you step through it

The agent queues every stop at once with kanna tour FILE:LINE "comment" … (code or markdown). Each comment has Back, where you are (2 of 5) and Next; Next opens or selects the next stop's tab and scrolls to it. Each step is sent to the agent as [kanna tour 2/5 · FILE:LINES], so it knows where you are and can add a line. A question in the middle is answered with a stop added right after the one you're on (kanna tour add --next), shown at once; Next then carries on with the tour. Click Back / Next on the comment itself.
