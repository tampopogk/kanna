Overview: a thumbnail of the whole file down the right edge of code and diff panes

As VS Code's minimap (overview-vscode.png): every line as tiny glyphs in the pane's colours, the part on screen as a box (shown while the pointer is over it), and a thin column of marks (changes, comments, find hits) that maps the whole file to the pane's height and carries the scroll thumb. Click the thumbnail to jump, drag the box to scroll. It's hidden when the file fits, and when the text beside it would keep fewer than 80 columns at the pane's font size; in a diff pane the file list (which wants 110 columns beside it) gives way first, and stays hidden while the overview is too narrow to show. View › Overview turns it off for every pane.
